# Click and Slide Game

A simple "Click and Slide" puzzle game built using HTML, CSS, and JavaScript.

## How to Play

1. **Enter your nickname** (optional) if you want your completion time to be recorded.
2. **Select an image** from the available options to use as the puzzle.
3. **Choose a difficulty level (game mode)** to start the game.
4. **Solve the puzzle** by sliding the tiles into the correct order.  
   - Once you complete the puzzle, the timer will stop, and your time will be saved in the leaderboard.


## Technologies Used

- HTML
- CSS
- JavaScript
